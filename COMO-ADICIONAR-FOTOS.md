# Como adicionar fotos ao site

As fotos ficam na pasta `fotos`, separadas por serviço:

| Pasta | Serviço |
|---|---|
| `fotos/impermeabilizacao` | Obras de Impermeabilização |
| `fotos/inspecao-de-fachadas` | Inspeção de Fachadas |
| `fotos/inspecao-predial` | Inspeção Predial |
| `fotos/fiscalizacao-de-obras` | Fiscalização de Obras |
| `fotos/projeto-avcb` | Projeto AVCB |
| `fotos/laudo-spda` | Laudo de SPDA |
| `fotos/carregadores-veiculos-eletricos` | Consultoria para Carregadores de Veículos Elétricos |

Toda foto enviada para uma dessas pastas aparece sozinha, em 1 a 2 minutos, em três lugares:
na página do serviço, na Galeria (com filtro por serviço) e na página inicial (as 8 mais recentes pelo nome).

## Pelo computador

1. Abra github.com/brenorochasouza/souzaengenharia e entre na pasta `fotos`.
2. Clique na pasta do serviço (ex.: `impermeabilizacao`).
3. Clique em **Add file** > **Upload files**.
4. Arraste as fotos para a página (pode enviar várias de uma vez).
5. Role até o fim e clique em **Commit changes**.

## Pelo celular

O aplicativo do GitHub não envia arquivos. Use o navegador do celular:

1. Abra github.com/brenorochasouza/souzaengenharia no Chrome ou Safari.
2. Toque nos três pontinhos do navegador e marque **Versão para computador** (Site para desktop).
3. Siga os mesmos passos acima (pasta do serviço > Add file > Upload files > Commit changes).

## Dicas

- **Formatos aceitos:** JPG, PNG ou WEBP. Fotos HEIC do iPhone não abrem no navegador: em Ajustes > Câmera > Formatos, escolha "Mais Compatível", ou envie a foto pelo WhatsApp para você mesmo e salve (o WhatsApp converte para JPG).
- **Tamanho:** fotos de até 1 a 2 MB deixam o site rápido. Fotos exportadas do WhatsApp já vêm leves. Limite do GitHub: 25 MB por arquivo.
- **Legenda:** o nome do arquivo vira legenda. `Cobertura-Condominio-Ike-Imbui.jpg` aparece como "Cobertura Condominio Ike Imbui". Arquivos com nome de câmera (IMG_1234, WhatsApp Image...) aparecem sem legenda.
- **Ordem:** as fotos aparecem em ordem decrescente de nome. Para controlar a ordem, comece o nome pela data: `2026-09-Cobertura-Ike-Imbui.jpg`.
- **Remover uma foto:** abra a foto no GitHub, clique nos três pontinhos (...) no canto superior direito e escolha **Delete file**, depois **Commit changes**.
- **Evite** fotos que identifiquem moradores, placas de carro ou documentos.
