# Logos dos clientes

Envie aqui os logos dos clientes que podem aparecer no site. Eles passam sozinhos na faixa "Empresas e condomínios que já confiaram no nosso trabalho".

- Formatos: PNG (de preferência com fundo transparente), JPG, WEBP ou SVG.
- O site mostra os logos em tons de cinza e coloridos ao passar o mouse.
- Nomeie o arquivo com o nome do cliente, por exemplo `rede-dor.png`. O nome vira o texto alternativo da imagem.
- Enquanto esta pasta estiver sem imagens, a faixa mostra os nomes dos clientes escritos no arquivo `_config.yml`.

Passo a passo para enviar: veja o arquivo COMO-ADICIONAR-IMAGENS.md na página inicial do repositório.
