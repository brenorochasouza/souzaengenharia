# Fotos de obras

Envie aqui as fotos das obras de impermeabilização. Elas aparecem no carrossel "Obras realizadas", dentro da seção de impermeabilização.

- Formatos: JPG, PNG ou WEBP. Fotos de até 1 a 2 MB deixam o site rápido.
- O nome do arquivo vira legenda: `Cobertura-Condominio-Ike-Imbui.jpg` aparece como "Cobertura Condominio Ike Imbui". Arquivos com nome de câmera (IMG_1234, WhatsApp Image...) aparecem sem legenda.
- Ordem: as fotos aparecem da maior para a menor pelo nome. Para controlar, comece o nome pela data: `2026-10-Piscina-Vila-Allegro.jpg` aparece antes de `2026-08-...`.
- Enquanto esta pasta estiver sem fotos, o carrossel não aparece.

Passo a passo para enviar: veja o arquivo COMO-ADICIONAR-IMAGENS.md na página inicial do repositório.
